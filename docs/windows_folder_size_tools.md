# Windows Folder Size Tools

A collection of recommended tools to check folder and disk space usage on Windows.

## Top Recommendations

### 1. **WizTree**
- **Cost:** Free
- **Best for:** Speed and performance
- **Features:**
  - Extremely fast scanning (uses MFT for speed)
  - Visual treemap display
  - Real-time folder size updates
  - Portable version available
- **Why use it:** Fastest option available, minimal resource usage

### 2. **TreeSize Free**
- **Cost:** Free
- **Best for:** Detailed analysis
- **Features:**
  - Shows folder sizes in a tree view
  - Filter and sort capabilities
  - Duplicate file finder
  - Clean and intuitive interface
- **Why use it:** Comprehensive features without the premium price

### 3. **SpaceSniffer**
- **Cost:** Free / Donation
- **Best for:** Visual learners
- **Features:**
  - Beautiful treemap visualization
  - Interactive navigation
  - Lightweight and portable
  - Color-coded categories
- **Why use it:** Excellent for understanding disk usage at a glance

## Honorable Mentions

### 4. **DiskDirStat**
- **Cost:** Free
- **Features:** Disk usage analyzer with visual sunburst chart display
- **Best for:** Understanding large folder structures visually

### 5. **Disk Usage Analyzer (WinDirStat alternative)**
- **Cost:** Free
- **Features:** Simple, straightforward folder analysis
- **Best for:** Minimal interface, quick scans

### 6. **Q-Dir**
- **Cost:** Free
- **Features:** Multi-panel file manager with size information
- **Best for:** Advanced users who want folder management + size analysis

### 7. **FastStone Disk Tools**
- **Cost:** Free / Premium version available
- **Features:** Comprehensive disk tools including size analysis
- **Best for:** All-in-one disk management solution

## Built-in Windows Options

### Storage Sense (Windows 10/11)
- **Cost:** Built-in (Free)
- **Features:**
  - Shows storage usage by category
  - Can automatically delete temporary files
  - Shows largest files and folders
- **Access:** Settings → System → Storage

### Disk Management
- **Cost:** Built-in (Free)
- **Features:** View disk partition sizes and free space
- **Access:** Right-click This PC → Manage → Disk Management
